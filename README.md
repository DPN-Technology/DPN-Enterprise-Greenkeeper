## 🧬 TELEMETRY & EVIDENCE STANDARD

**Every repository:** default-branch SHA, individual check results, open PR count, security findings and release status.

**Every pull request:** exact head SHA, draft/conflict state, required reviews, protection rules, named failing/pending checks, remediation owner and next action.

**Every intervention:** evidence → root cause → focused change → commit → rerun → verified gate result. Merge only on the exact tested SHA with required protections satisfied.

**Every release:** verified default-branch health, version consistency, reproducible artifacts, changelog and checksums where supported.

**Every hourly transmission:** timestamp, inventory completeness, full evidence links, actions attempted, blocked writes, and change since the previous completed run.
